# Changelog

All notable changes to DryMark are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Preserve and Thorough LLM watermark removal policies.
- Context-aware protection for recognized emoji, shaping-script joiners,
  variation sequences, subdivision flags, and balanced bidi isolates.
- A generated Unicode 17 emoji automaton with exhaustive registry coverage and
  an asserted linear probe budget.
- Fail-closed iteration budgets for generated-table searches, with direct
  branch tests and a zero-survivor mutation baseline.
- Removal reporting that contains counts and stable categories only.
- Race-aware, size-limited clipboard replacement with zeroizing snapshots and
  immediate post-write text verification.
- Cross-platform tray application, configurable global shortcut, settings, and
  silent visual feedback.
- Streaming CLI with clean, scan, JSON, and check modes.
- Property, integration, privacy, UI, fuzz, and mutation test suites.
- Process-wide redacted panic reporting that never prints panic payloads.
- Cross-platform CI, dependency auditing, and open-source project templates.
- One-command macOS, Linux, and Windows source setup, including verified staged
  macOS installation and recoverable replacement of a previous app.
- An EU and German legal-use boundary covering transparency marks, copyright
  measures, rights-management information, signed provenance, and deception.
