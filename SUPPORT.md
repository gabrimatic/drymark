# Support

## Questions and Bugs

Use [GitHub Issues](https://github.com/gabrimatic/drymark/issues) for
reproducible bugs and focused feature requests. Search existing issues first.

Include:

- DryMark version and operating system.
- Preserve or Thorough policy.
- The surface used: shortcut, tray, Settings, or CLI.
- Expected and actual behavior.
- A synthetic minimal reproduction with code points written as `U+XXXX`.

Do not paste private clipboard content, tokens, credentials, or proprietary
documents into an issue.

For vulnerabilities, use [private vulnerability reporting](SECURITY.md).
