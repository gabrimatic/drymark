# Code of Conduct

## Our Standard

Be respectful, precise, and constructive. Welcome people of different
backgrounds and experience levels. Critique code and claims, not people.

Examples of positive behavior include:

- Giving actionable feedback with evidence.
- Respecting privacy and using synthetic examples.
- Acknowledging uncertainty in language- and platform-specific behavior.
- Accepting correction and helping others improve a contribution.

Harassment, discrimination, threats, sexualized attention, deliberate exposure
of private data, and sustained disruptive behavior are not acceptable.

## Enforcement

Project maintainers may edit, remove, or reject contributions and may
temporarily or permanently restrict participation when behavior violates this
standard. Reports can be sent privately through the repository's security
advisory form when public discussion would expose personal information.

This code applies in project spaces and when representing the project in public.
